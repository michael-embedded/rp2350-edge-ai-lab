# TinyML Experiments on RP2350

This section explores TinyML deployment on Raspberry Pi Pico 2 (RP2350).

Focus areas:
- Model size vs flash usage
- SRAM consumption during inference
- Inference latency (ms)
- Quantization effects
- Edge event detection experiments

Hardware:
- Raspberry Pi Pico 2
- USB power meter
- Optional MEMS microphone or accelerometer
