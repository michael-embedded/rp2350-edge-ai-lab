# RP2350 Edge AI Lab

Practical embedded experiments on Raspberry Pi Pico 2 (RP2350).

This repository documents hands-on experiments covering:

- GPIO fundamentals
- ADC & PWM control
- Sensor interfacing (I2C, SPI, UART)
- TinyML deployment on microcontrollers
- Low-power system design and sleep optimization

## Why This Repository Exists

RP2350 (Pico 2) is still relatively new. This lab focuses on:

- Measured power consumption (active vs sleep)
- Flash and SRAM usage analysis
- TinyML inference timing
- Real-world constraints and failure cases

## Hardware Used

- Raspberry Pi Pico 2 (RP2350)
- Basic push buttons and LEDs
- BME280 (I2C sensor)
- USB power meter for current measurements

All examples are tested and reproducible.
